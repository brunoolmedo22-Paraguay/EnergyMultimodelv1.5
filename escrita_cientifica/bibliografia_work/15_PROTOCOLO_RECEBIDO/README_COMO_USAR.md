# SEEDS2 — Paquete de misión bibliográfica para ChatGPT Work

**Preparado:** 12/11/2026.

## Cómo ejecutar
1. Abre una conversación nueva en **ChatGPT Work**.
2. Adjunta este ZIP (si la interfaz permite ZIP) o, preferentemente, adjunta el archivo `00_PROMPT_PARA_WORK.md`. El prompt es AUTOCONTENIDO y se puede pegar íntegro en Work.
3. Indica: **«Ejecuta íntegramente la misión adjunta. Audita primero GitHub en modo solo lectura; después investiga la literatura; entrega el repositorio bibliográfico y los archivos de trazabilidad solicitados. No modifiques el código.»**
4. Si Work solicita acceso a una biblioteca institucional, usa únicamente tu acceso legítimo. Si no hay acceso, continúa con fuentes abiertas y documenta limitaciones.
5. Cuando Work entregue resultados, verifica el ZIP contra `04_CHECKLIST_DE_RECEPCION.md`; entonces podremos convertir las fuentes en una base crítica para escribir el artículo.

## El contenido del ZIP
- `00_PROMPT_PARA_WORK.md`: encargo completo y autónomo, suficientemente detallado para otro agente.
- `01_PROTOCOLO_Y_PRIORIZACION.md`: métricas y reglas de rigor.
- `02_ESTRATEGIAS_BUSQUEDA_EN.md`: estrategias para buscadores académicos.
- `03_MAPA_ARTICULO_Y_REFERENCIAS.md`: secciones del artículo y evidencia bibliográfica requerida.
- `04_CHECKLIST_DE_RECEPCION.md`: condiciones de aceptación de la entrega.
- `plantillas/MATRIZ_INVESTIGACION_SEEDS2.xlsx`: libro inicial con hojas de bibliografía, trazabilidad código, afirmaciones, búsquedas y vacíos.
- `plantillas/referencias.bib`: cabecera vacía para las referencias bibliográficas comprobadas.
- `plantillas/README_MATRIZ.md`: explicación de campos y clasificaciones.

**Importante:** estos archivos son la especificación de la misión y plantillas vacías. NO son la investigación bibliográfica terminada, NO contienen 50 artículos ficticios y NO representan una auditoría matemática del repositorio.

## Convenciones
- Objetivo: >=50 referencias sólidas comprobadas y descritas individualmente; prospectar 200–300 candidatos cuando la literatura lo permita.
- Priorización dual: P0 fuente directa de modelo; P1 estudios próximos SEEDS2/EMS; P2 tecnología/método; P3 software/validación; P4 contexto. Grado de lectura: F texto completo, A resumen, M metadatos.
- La revista Elsevier *Measurement: Digitalization* es una posible opción editorial. No sesgar el estado del arte para acomodar artificialmente el artículo a su alcance.
- Idioma de los informes para TCC: portugués (Brasil). Consultas prioritariamente en inglés.
