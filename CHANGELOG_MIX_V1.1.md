# MIX v1.1

- A página **Configuração de fontes** passa a ser soberana sobre os CSVs.
- Colunas/variáveis pertencentes a fontes desativadas são ignoradas completamente.
- O MIX mostra uma advertência quando detecta dados de uma fonte desligada e continua a execução sem considerá-la.
- Alterar o switch de uma fonte invalida a execução anterior para evitar visualizar resultados incompatíveis com a configuração atual.
- KPIs, tabela consolidada e opções de exportação deixam de exibir colunas específicas de fontes desativadas.
- Nenhum modelo físico foi alterado.
